# ☕ Cata Origen Café - Landing Page

Landing page ficticia diseñada para un café de autor en Bogotá.  
Este proyecto forma parte de mi portafolio como desarrollador web y muestra el diseño, interactividad y simulación de funcionalidades de un sitio real de cafetería.

---

## 🚀 Funcionalidades

- **Diseño responsivo**: Adaptado a desktop, tablet y móvil.  
- **Reservas online**: Formulario con validación en tiempo real, selección de fecha/hora y número de personas.  
- **Carrito de compras simulado**: Posibilidad de añadir productos del menú y finalizar compra.  
- **Menú interactivo**: Café, postres, brunch, jugos y smoothies con galería de imágenes.  
- **Calificaciones**: Sistema de opiniones con estrellas (tazas de café interactivas) y comentarios.  
- **Galería de fotos**: Presentación tipo grid de imágenes de productos y espacio.  
- **Mapa interactivo**: Integración con Google Maps (ubicación ficticia).  
- **Accesibilidad**: Etiquetas `alt`, roles y navegación por teclado.  
- **Animaciones y transiciones**: Efectos suaves en scroll y acciones del usuario.  

---

## 🛠️ Tecnologías usadas

- **HTML5**  
- **CSS3** (Flexbox, Grid, animaciones, responsive design)  
- **JavaScript (ES6+)**
